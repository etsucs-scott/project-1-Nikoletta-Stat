# CSCI 1260 — Project

Nikoletta's Adventure Game

- This is a simple text based adventure game where a player navigates through a maze towards an exit. A player has the opportunity to pick up items such as weapons and potions to increase attack modifiers and health stats. If a player encounters a monster in the maze, a battle will commence and players and monsters will lose health until one of them dies. If the player dies, the game is over. If the monster dies, the player takes the monster's spot and continues in the maze to the exit.
- This project was designed in Visual Studio.
- It is built and ran from the AdventureGame.Cli folder.
- Running the program will immediately generate a new game with a randomized 10x10 maze.
- Players can use WASD or the arrow keys to move through the maze. The program reads in key input and will display an error message if the key is invalid.
